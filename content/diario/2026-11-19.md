# 2026-11-19

## O que foi feito

- **Aba Jogos voltou.** Conta nova da API-Football (grátis), chave trocada
  no Railway (`API_FOOTBALL_KEY`). Pedidos saem pelo IP do VPS via
  [[sistemas/apifootball-relay]]. Primeiro teste: 3 jogos da Série A com escudos.

- **Download do Sofae corrigido.** O `baixar.html?brand=Sofae` só trocava o nome: os links
  eram fixos do SimanPlay (APK `tinyurl 24bjey5l` e `SimanPlay.Setup.1.0.0.exe`). Agora tem
  tabela por marca. Instalador `Sofae-Setup.exe` publicado na release fixa `sofae-windows`.
  Testado: Windows abre como Sofae, com a aba Jogos.

## O que custou tempo

- Primeiros pedidos ainda deram "account suspended": o Railway mandava a
  chave antiga até o redeploy terminar. O teste de `/status` direto do VPS
  separou "conta ruim" de "chave não trocada".

- Inno Setup falhou no run #8: o Git Bash (MSYS) converte argumentos `/DNome=...` em
  caminhos. Correção: `MSYS_NO_PATHCONV=1` e `MSYS2_ARG_CONV_EXCL='*'` no passo.
